# Symposium — the manual

The user's manual for **Symposium**, a spoken iOS app in which philosophers
argue in their own voices and may cite only what they actually wrote.

One self-contained HTML file. No build step, no dependencies, no tracking.

**Read it:** https://gude2000.github.io/symposium-manual/

The source of truth lives in the app repository; this copy exists so the manual
can be opened by somebody who does not have the app, on a phone, without an
account.
